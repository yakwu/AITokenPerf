# E2E 测试与 Pre-push Hook 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现 Playwright E2E 测试套件 + git pre-push hook，每次推送前自动运行测试防止回归。

**Architecture:** 后端通过 `E2E_TEST_MODE` 环境变量启用测试模式，拦截出站 AI API 请求返回模拟响应。Playwright Test 通过 `webServer` 配置自动管理前后端服务生命周期。git pre-push hook 调用 `scripts/e2e-run.sh` 运行测试。

**Tech Stack:** Playwright Test (Node.js), FastAPI (Python), Vue 3 + Vite (前端)

```python
#!/usr/bin/env python3
"""E2E 测试模式 — 拦截出站 AI API 请求，返回模拟 SSE 响应"""

import asyncio
import json
import time
from typing import Optional

from app.client import RequestMetrics


# 固定模拟参数
MOCK_DELAY = 0.05  # 50ms 模拟延迟
MOCK_INPUT_TOKENS = 100
MOCK_OUTPUT_TOKENS = 50
MOCK_TOKEN_CONTENT = "Test "  # 每个 token 的内容


def _build_openai_chat_sse() -> list[str]:
    """构建 OpenAI Chat Completions 格式的 SSE 事件列表"""
    lines = []
    for i in range(MOCK_OUTPUT_TOKENS):
        chunk = {
            "choices": [{"delta": {"content": MOCK_TOKEN_CONTENT}, "finish_reason": None}]
        }
        lines.append(f"data: {json.dumps(chunk)}\n\n")
    # 最后一个 chunk 带 usage
    final_chunk = {
        "choices": [{"delta": {}, "finish_reason": "stop"}],
        "usage": {
            "prompt_tokens": MOCK_INPUT_TOKENS,
            "completion_tokens": MOCK_OUTPUT_TOKENS,
            "total_tokens": MOCK_INPUT_TOKENS + MOCK_OUTPUT_TOKENS,
        },
    }
    lines.append(f"data: {json.dumps(final_chunk)}\n\n")
    lines.append("data: [DONE]\n\n")
    return lines


def _build_anthropic_sse() -> list[str]:
    """构建 Anthropic 格式的 SSE 事件列表"""
    lines = []
    # message_start
    msg_start = {
        "type": "message_start",
        "message": {"usage": {"input_tokens": MOCK_INPUT_TOKENS}},
    }
    lines.append(f"data: {json.dumps(msg_start)}\n\n")
    # content_block_delta
    for i in range(MOCK_OUTPUT_TOKENS):
        delta = {
            "type": "content_block_delta",
            "delta": {"type": "text_delta", "text": MOCK_TOKEN_CONTENT},
        }
        lines.append(f"data: {json.dumps(delta)}\n\n")
    # message_delta (output_tokens)
    msg_delta = {
        "type": "message_delta",
        "usage": {"output_tokens": MOCK_OUTPUT_TOKENS},
    }
    lines.append(f"data: {json.dumps(msg_delta)}\n\n")
    # message_stop
    lines.append(f'data: {{"type": "message_stop"}}\n\n')
    return lines


def _build_openai_responses_sse() -> list[str]:
    """构建 OpenAI Responses API 格式的 SSE 事件列表"""
    lines = []
    for i in range(MOCK_OUTPUT_TOKENS):
        event = {
            "type": "response.output_text.delta",
            "delta": MOCK_TOKEN_CONTENT,
        }
        lines.append(f"data: {json.dumps(event)}\n\n")
    # 完成事件
    done_event = {"type": "response.done", "response": {"usage": {"input_tokens": MOCK_INPUT_TOKENS, "output_tokens": MOCK_OUTPUT_TOKENS}}}
    lines.append(f"data: {json.dumps(done_event)}\n\n")
    return lines


async def mock_send_streaming_request(
    config: dict,
    request_id: int,
) -> RequestMetrics:
    """模拟 send_streaming_request，返回预设指标，不发出真实 HTTP 请求。"""
    from app.protocols import detect_protocol

    metrics = RequestMetrics(request_id=request_id)
    protocol = config.get("protocol") or detect_protocol(
        config.get("model", ""), config.get("provider", "")
    )

    # 模拟网络延迟
    await asyncio.sleep(MOCK_DELAY)

    metrics.start_time = time.monotonic()
    metrics.first_token_time = time.monotonic()
    metrics.status_code = 200
    metrics.input_tokens = MOCK_INPUT_TOKENS
    metrics.output_tokens = MOCK_OUTPUT_TOKENS
    metrics.success = True

    # 模拟 token 时间戳
    for i in range(MOCK_OUTPUT_TOKENS):
        metrics.token_timestamps.append(time.monotonic())

    metrics.end_time = time.monotonic()
    metrics.url = f"mock://e2e-test/{protocol}"

    return metrics
```

- [ ] **Step 3: 修改 Vite 配置支持可变代理目标**

当前 `frontend/vite.config.js` 的 proxy 目标硬编码为 `http://localhost:8080`。需要改为读取环境变量，使 e2e 测试可以指向测试后端端口。

修改 `frontend/vite.config.js`，将 proxy target 改为环境变量：

```javascript
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import { resolve } from 'path'

export default defineConfig({
  plugins: [vue()],
  resolve: {
    alias: {
      '@': resolve(__dirname, 'src'),
    },
  },
  test: {
    environment: 'jsdom',
  },
  server: {
    port: 5180,
    strictPort: true,
    proxy: {
      '/api': {
        target: process.env.VITE_PROXY_TARGET || 'http://localhost:8080',
        changeOrigin: true,
      },
    },
  },
  build: {
    outDir: '../static',
    emptyOutDir: true,
  },
})
```

同时修改 `frontend/src/api/index.js` 第 7 行，让 dev 模式也走相对路径（通过 Vite proxy），而非硬编码绝对地址：

```javascript
// 原代码：
const apiBase = window.__API_BASE__ || (import.meta.env.DEV ? 'http://localhost:8080' : '');
// 改为：
const apiBase = window.__API_BASE__ || '';
```

这样 dev 模式下 `/api/...` 请求会走 Vite proxy，由 proxy 转发到正确的后端端口。

#!/bin/bash
# git pre-push hook — 运行 E2E 测试

# 跳过 --no-verify
if echo "$@" | grep -q -- "--no-verify"; then
  exit 0
fi

# 只在 dev/main 分支运行
BRANCH=$(git rev-parse --abbrev-ref HEAD)
if [[ "$BRANCH" != "dev" && "$BRANCH" != "main" ]]; then
  exit 0
fi

echo "🔍 Pre-push: running E2E tests..."
exec bash scripts/e2e-run.sh
